
# Brain Tumor Detection Using CNN

## Overview
A deep learning project for classifying brain MRI images
using a Convolutional Neural Network (CNN). The project
uses Python and TensorFlow for image classification and
Flask for application and REST API integration.

## Technologies
- Python
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- Flask
- REST API
- NumPy and Pillow

## Features
- MRI image preprocessing
- CNN-based image classification
- Model prediction through a Flask application
- REST API integration for image inputs

## Setup
1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Prepare the MRI dataset and train the model.
5. Configure the application to load the trained model.
6. Run the Flask application.

## Model Evaluation
Evaluate the model using a held-out validation or test set.
Report accuracy and other relevant metrics only after
running the evaluation.
